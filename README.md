## How to read this portfolio

Start with **ArchRules** for architecture enforcement, or **MCP SQL Read-only** for a small integration with explicit security boundaries. CredentialPlatform and Jano show how I approach larger business applications that are still evolving.

The private-project summaries describe selected decisions as of **October 2026**. They do not claim production readiness, deployment at a named customer, measured business impact or independent certification. Diagrams are simplified views of responsibilities.
